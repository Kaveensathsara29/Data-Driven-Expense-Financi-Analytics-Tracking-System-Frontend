# 📊 Data-Driven Expense & Financial Analytics Tracking System - Frontend

A responsive client application built with Angular and Tailwind CSS for tracking income streams, managing recurring expenses, and visualizing real-time financial metrics.

---

## ✨ Key Features

- 💰 **Real-Time Financial Analytics** — Dynamic dashboard displaying income streams, recurring expenses, and live balance calculations.
- 🎯 **Budget Allocation & Categorization** — Intuitive UI components to manage custom expense categories and financial goals.
- ⚡ **Optimized Data Fetching** — Integrated GraphQL client queries to prevent over-fetching and speed up client rendering.
- 📱 **Modern & Responsive UI** — Clean interface styled using Tailwind CSS for a seamless desktop and mobile experience.

---

## 🛠 Tech Stack

- **Framework:** Angular
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **API Client:** Apollo Client / GraphQL
